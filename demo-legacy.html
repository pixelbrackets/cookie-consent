🍪 Cookie Consent Demo - Legacy

⚠️ Consent by continued usage is not EU-compliant since 2020. Use it in non-EU regions only.

Visiting the page sets level 20 for 8 hours and keeps the consent bar visible. Clicking "OK" sets level 80 for 1 year and hides the bar.

The example demo-tracker.js script reads the level once on page load and outputs different messages to the browser console - open the developer tools (F12) to see them. Reload the page to see the level set by continued usage, and again after clicking the button.

🍪 Cookie Consent Demo - Best practice

EU-compliant best practice with multiple buttons for different consent levels: "Necessary cookies only" (level 0) or "Accept all cookies" (level 80). The consent bar is shown until the user clicks one of the buttons.

The example demo-tracker.js script reads the level once on page load and outputs different messages to the browser console. Reload the page after clicking a button to see which tracking scripts would be activated.

🍪 Cookie Consent Demo - Minimal

No data-level or data-duration attributes are set, so the script uses its fallback values. Visiting the page sets level 1 and keeps the consent bar visible. Clicking the button sets level 50 for 8 hours and hides the bar.

The example demo-tracker.js script reads the level once on page load and outputs different messages to the browser console - open the developer tools (F12) to see them. Reload the page after clicking the button to see which tracking scripts would be activated.

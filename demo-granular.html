🍪 Cookie Consent Demo - Granular

EU-compliant opt-in with one button per cookie category: "Necessary cookies only" (level 0), "Allow comfort cookies" like YouTube videos (level 70) or "Accept all cookies" including tracking (level 80). Levels are cumulative, so each level includes all lower levels. The consent bar is shown until the user clicks one of the buttons.

The example demo-tracker.js script reads the level once on page load and outputs different messages to the browser console. Reload the page after clicking a button to see which tracking scripts would be activated.
